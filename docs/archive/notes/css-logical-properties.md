---
title: "logical properties over left and right"
date: 2026-01-21
tags: [css]
---

`margin-inline-start` instead of `margin-left`, `padding-block` instead of `padding-top` plus `padding-bottom`.

Even on a left-to-right only site the block/inline naming reads better once it is habit. Tailwind has `ms-`, `me-`, `ps-`, `pe-` for the same thing.
